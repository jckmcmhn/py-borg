# Py Borg
A recreation of the popular TTRPG Mörk Borg in Python

# About the name
I really wanted to call this Förk Borg because "fork" is github word and this is... on github, you get the idea.

But it turns out a Mörk Borg project called "Förk Borg" already [exists](https://reverse-ettin-games.itch.io/frk-borg-the-book-of-feast-and-famine), some dreams aren't meant to come true.

Py Borg was the next most obvious name, but I should clarify that this is an adaptation of the Mörk Borg rules specifically, and not CY_BORG, it's techno dystopia spin-off that thematically probably would have been a better fit for the aesthetics of a game you run on the command line... d'oh!
